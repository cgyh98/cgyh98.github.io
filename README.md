# cgyh98.github.io

Personal site of Gabriela Yaulli, live at https://cgyh98.github.io/.

Plain HTML, CSS and JavaScript, with no build step. GitHub Pages serves the files as they are.

- `content.js` holds every word on the site. Edit it to change text, projects, work or talks.
- `site.js` renders that content into the pages.
- `map.js` places the pins and routes on the projects-page map. The land drawing is pre-generated and inlined in `projects.html`.
